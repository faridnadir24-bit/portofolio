## 📂 5 Proyek Utama & Inovasi

1. **AVO-BIO** *(Smart IoT & AI Biogas Yield Predictor)*
   - Dashboard monitoring biogas real-time ESP32 + MQTT dengan prediksi volume gas & deteksi anomali digester (Juara 1 Nasional KNEC 2026).
2. **PANGANARA AI** *(AI & 38-Province Heritage Platform)*
   - Platform digitalisasi pangan tradisional nusantara berbasis peta spasial interaktif GeoJSON dan AI Semantic Search.
3. **SIRKULAR** *(AI Computer Vision Marine Waste Detection)*
   - Deteksi objek sampah plastik laut di muara sungai menggunakan Python YOLOv8 & OpenCV.
4. **NERACA** *(Data Science & Food Crisis Forecasting)*
   - Sistem peramalan kerentanan pangan berbasis dinamika neraca massa air & pemodelan time-series LSTM.
5. **POS Resto & Billing** *(F&B Offline-Ready Cloud POS)*
   - Aplikasi kasir restoran full-stack dengan Kitchen Display System (KDS), IndexedDB offline support, dan Supabase Realtime sync.

## 💻 Menjalankan Proyek Secara Lokal

```bash
# Clone repository
git clone https://github.com/faridnadir24-bit/portofolio.git

# Masuk ke direktori
cd portofolio

# Install dependensi
npm install

# Jalankan server lokal
npm run dev
```
